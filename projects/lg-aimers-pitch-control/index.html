LG Aimers: Pitch Control Prediction

Team leader

Predicting and calibrating pitch-control success probabilities from game context and historical player data.

LG Aimers 9th, leaderboard 88th

Code

Problem

Estimate pitch-control success before a pitch using the count, runners, player characteristics and historical observations. The test season differs from the seasons used for training.

Approach

Led feature development, model comparison, validation and submission. Combined tree-based models and residual signals with segment-wise probability calibration, using chronological validation to study season changes.

Result

Finished 88th on the hackathon leaderboard with a score of 1,149.33143. Completed the LG Aimers 9th program.

Resources

The public repository documents the selected submission and its feature, model and inference structure. See its README for the released files and execution requirements.
