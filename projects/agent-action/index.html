Next-Action Prediction for Coding Agents

Team leader

Predicting a coding agent’s next tool action with session-level validation, controlled input experiments and compact inference.

Code

Problem

Predict the next tool action among 14 classes from conversation history and agent state, while meeting submission size and execution-time constraints.

Approach

Led the project and organized parallel analysis and model experiments. Split validation by session to avoid mixing records from the same conversation across training and evaluation. Packaged the ensemble with vocabulary reduction and int8 conversion.

Controlled comparison

Compared input designs on the same 14,001-example validation set. The baseline reached Macro-F1 0.7562, added cues 0.7542, and reordered input 0.7565, indicating that the tested input changes had little effect.

Resources

The repository includes source code, analysis figures, experiment records and the documented inference package.
