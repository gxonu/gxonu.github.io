Text-Guided Image Colorization

Team leader

Colorizing grayscale images from text with DDColor and FLUX candidates, selected per image using CLIP similarity.

Undergraduate Excellence Award, BK21 Director’s Award

CodeCertificate

Problem

Recover color from a grayscale image while following the objects and colors described in a text prompt.

Approach

Led the project from model selection and evaluation to final submission. Generated candidates with DDColor and FLUX.1-dev with ControlNet, then used CLIP ViT-L/14 to select the candidate that best matched each text description.

Result

Received the undergraduate Excellence Award (BK21 Director’s Award) in the 2025 Text-Guided Colorization AI Challenge at Inha University.

Resources

The repository includes integrated inference code, model-specific notebooks and submission packaging. See the README for required model access and input data.
